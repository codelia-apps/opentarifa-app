# opentarifa-app
App Android de precio de luz PVPC — OpenTarifa

Precios de la luz (PVPC) hora a hora, claros y sin complicaciones. Los datos se obtienen de la API pública de Red Eléctrica de España (REE). No incluye Ceuta y Melilla, que tienen un sistema eléctrico propio.

## Funcionalidades

- Precio de la luz hora a hora, para hoy y para mañana (en cuanto REE los publica).
- Resumen con la evolución hora a hora del día actual y el ahorro estimado.
- Alertas de precio configurables, con notificaciones y creación de eventos en el calendario.
- Calculadora de consumo de electrodomésticos.
- Consejos de ahorro y guía del bono social.

## Open source y privacidad

Este proyecto es 100% open source bajo licencia [GPLv3](LICENSE).

- Sin publicidad.
- Sin rastreo ni analítica.
- Sin dependencias de Google Play Services, Firebase ni Crashlytics.
